# 妙手 TikTok 越南站定价（CNY 成本 → VND 建议售价）

把 1688 人民币采购成本，按**已在货叮咚生产环境验证**的越南站费率模板，换算成越南盾建议售价，确保每单有合理利润。本技能**只读计算**，不写入妙手。

## 何时用

- 「这个商品越南店卖多少钱」「帮我定价」「换算成越南盾」
- 「这个价格赚多少 / 会不会亏」「保本价是多少」
- 引流品起号定价、常规品/利润款定价
- 上游：`mss-1688-sourcing`（采集）→ `miaoshou-erp-product-claim`（认领）→ **本技能（定价）** → `miaoshou-erp-tiktok-product-edit`（把算好的 VND 价写进 SKU）

## 核心模型

所有百分比费率**以售价为基数**叠加：

```
总变动费率 = 平台佣金16.1% + 交易手续费5% + 提现1% + VAT10% + 达人佣金10%(可选)
           含达人佣金 = 42.1%；不走联盟(新店) = 32.1%
卖家单位成本(CNY) = 采购成本 + 订单处理0.77 + 货代2.0 + 头程运费(卖家担,按重量)
           注：尾程运费7.71CNY由买家付(商家承担部分运费未勾)，不计卖家成本
保本价(CNY) = 单位成本 / (1 - 总变动费率)
目标利润价  = 单位成本 / (1 - 总变动费率 - 目标利润率)
售价(VND)   = CNY价 × 汇率(3875)，再取 x9,000 心理尾价(299,000/379,000…)，且不低于保本价
```

| 参数 | 值 | 说明 |
|---|---|---|
| 平台佣金 | 16.1% | 货叮咚生产值；妙手API默认5.78%偏低（服装类目实际更高），**采用生产值保利润** |
| 交易手续费 | 5% | 妙手API默认6% |
| 提现手续费 | 1% | 两平台一致 |
| VAT | 10% | 两平台一致 |
| 达人佣金 | 10% | 仅联盟订单产生；新店无达人可用 `--no-affiliate` 算底价 |
| 订单处理费 | 0.77 CNY | 固定 |
| 货代费用 | 2.00 CNY | 固定 |
| 头程运费 | 按重量 | 官方跨境物流，**必须按实际包裹重量查官方运价表**，模板默认8CNY为轻小件占位 |
| 尾程运费 | 7.71 CNY | 买家付，不计成本（妙手买家物流默认7.74CNY/30000VND 印证） |
| 汇率 | 1CNY=3875VND | 2026-08-31，**波动大，定价前刷新** `pricing_template_vn.json` 的 `fx` |

## 操作流程

### 第 1 步：确认两个关键输入

向用户确认（或从采集箱商品读取）：
1. **采购成本**（CNY）：1688 拿货价（采集箱里的人民币价格）
2. **包裹重量**（KG）：用于头程运费。头程是本模板唯一需按件核实的变量。

> 头程运费务必让用户按实际重量在妙手/货叮咚「查看官方运价差」核实，用 `--head-leg <CNY>` 传入；不传则用模板占位 8 CNY（轻小件 0.3–0.5kg 服装），结果偏乐观，须提示。

### 第 2 步：跑定价（含达人佣金 = 建议上架价）

```powershell
py "<skills根目录>/mss-vn-pricing/scripts/vn_pricing.py" --cost <采购成本CNY> --weight <重量KG>
```

输出三档：引流品(8%利润) / 常规品(18%) / 利润款(25%)，各给 CNY 价、x9,000 VND 建议价、单件利润，外加保本价。

### 第 3 步：新店无联盟时算底价（可选）

```powershell
py "<skills根目录>/mss-vn-pricing/scripts/vn_pricing.py" --cost <成本> --weight <KG> --no-affiliate
```

新店没达人带货时实际不产生 10% 达人佣金，费率降到 32.1%，底价更低；但**建议按含佣价上架**，为后续开联盟留空间。

### 第 4 步：自定义利润率（可选）

```powershell
py "<skills根目录>/mss-vn-pricing/scripts/vn_pricing.py" --cost <成本> --margin 0.15
```

### 第 5 步：把 VND 价写入 SKU

用 `miaoshou-erp-tiktok-product-edit` 的改价能力，把建议售价（VND）写进对应 SKU；库存统一改 555。**本技能只算价、不写价。**

## 踩坑提示

1. **头程运费是最大变量**：8 CNY 是轻小件占位，重货/泡货必须查官方运价，否则定价偏低亏本。
2. **平台佣金用 16.1% 而非妙手 API 的 5.78%**：后者是基础类目费率，服装跨境实际综合更高；用生产值更稳。
3. **尾程运费别重复计成本**：买家付，计入会让售价虚高失去竞争力。
4. **汇率要刷新**：VND 波动大，模板 `fx.cny_to_vnd` 定价前更新。
5. **达人佣金是预算不是必扣**：`--no-affiliate` 看真实底价，含佣价上架留联盟空间。
6. **心理尾价 x9,000 不破保本**：计算器取整时自动以保本价为底，只上不下。
7. 本模板与 `miaoshou-erp-tiktok-profit-operations`（妙手官方只读定价 API）互补：官方 API 查站点默认费率/模板，本技能用货叮咚生产参数做可落地的 VND 定价。

## 文件

- `pricing_template_vn.json`：越南站费率/固定成本/汇率/尾价/利润档参数（单一事实源，改参数改这里）
- `scripts/vn_pricing.py`：定价计算器（PEP8，含注释/docstring）
